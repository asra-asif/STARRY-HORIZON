## 🪐 About The Project

**Starry Horizons** is an immersive, space-themed website that brings the wonders of the cosmos right to your browser. Designed for space enthusiasts, curious explorers, and astronomy lovers, this platform offers an elegant and interactive journey through our solar system and beyond.

Whether you're gazing at stunning planet imagery, exploring space-themed products, or simply getting lost in the cosmic gallery — Starry Horizons makes space feel closer than ever.

> *"Our Journey to the Stars is Just the Beginning."*

## 🛠️ Getting Started

No frameworks, no build tools — just pure HTML, CSS, and JavaScript. Getting this running locally is incredibly simple!

### Prerequisites

- Any modern web browser (Chrome, Firefox, Edge, Safari)
- A code editor (e.g., [VS Code](https://code.visualstudio.com/))
- Optionally: [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension for auto-reload

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/your-username/STARRY-HORIZON.git

# 2. Navigate into the project folder
cd STARRY-HORIZON

# 3. Open index.html in your browser
#    OR right-click index.html → "Open with Live Server" in VS Code
```

That's it! No `npm install`, no build process. 🎉

## 🎨 Design System

The entire site is built around a cohesive **deep-space aesthetic**:

```css
/* Color Palette */
--background:    #060809   /* Deep space black */
--accent:        #72a1de   /* Cosmic blue glow */
--text-primary:  #ffffff   /* Starlight white */
--text-muted:    #cad6f2   /* Nebula lavender */
```

**Key Design Decisions:**
- 🌑 **Dark-first design** — every section uses deep space tones
- 💫 **Smooth animations** — fade-in-text, hover reveals, scale transforms
- 📱 **Mobile hamburger menu** — responsive nav that collapses on small screens
- ✨ **Glow effects** — neon blue box-shadows on interactive elements
